### 🧱 Foundation — Modular Java Framework

**🌍 Open Source** · **☕ Java 25** · **📦 Maven Multi-Module**

🔗 **[Explore Foundation on GitHub](https://github.com/TR4E/Foundation)**

Foundation is a **modular Java framework** designed to provide reusable, high-performance infrastructure for backend applications, Minecraft platforms, and Spring Boot services.

Built with **modularity, extensibility, and reliability** in mind, Foundation provides independent modules that can be integrated individually without requiring the entire framework.

#### 🧩 Framework Modules

| Module | Description |
| --- | --- |
| 🗄️ **Database** | PostgreSQL persistence, Redis integration, multi-layer caching, schema management, entity repositories, batched writes, and distributed cache synchronization. |
| 💉 **Injector** | Lightweight dependency injection with automatic component discovery, constructor injection, lifecycle management, and extensible component resolution. |
| 🎮 **Minecraft** | Reusable Paper and Velocity frameworks with plugin lifecycle management, developer APIs, and optional gameplay components. |
| 🍃 **Spring** | Spring Boot components for request rate limiting, HTTP security, page routing, caching, and web application infrastructure. |
| 🛠️ **Utilities** | Java utilities for reflection, HTTP, cryptography, hashing, file handling, data conversion, and general-purpose development. |

#### ⚡ Engineering Highlights

- 🔄 **Distributed Persistence** — PostgreSQL and Redis integration with cross-instance cache synchronization.
- 🚀 **Multi-Layer Caching** — Local Cache → Redis → Database retrieval with efficient cache management.
- 📦 **Batch Processing** — Optimized database writes, entity change tracking, and persistence operations.
- 💉 **Dependency Injection** — Component discovery, dependency resolution, lifecycle hooks, and modular extensions.
- 🛡️ **Application Security** — Reusable Spring Boot security and configurable rate limiting.
- 🧩 **Modular Architecture** — Independent Maven modules with well-defined APIs and responsibilities.
- 🎮 **Platform Integration** — Extensible frameworks supporting Paper and Velocity applications.

**🛠️ Technology Stack**

### 🌐 Nexus — Distributed Game Network Infrastructure

**🔒 Private / Proprietary** · **☕ Java 25** · **🌐 Distributed Systems**

Nexus is a **game-agnostic distributed infrastructure framework** designed to coordinate game servers, proxies, and players across scalable, multi-instance networks.

It provides a shared infrastructure layer for **network state, instance lifecycle management, player routing, distributed messaging, and automated provisioning**.

Built around a modular Java architecture with Redis-backed synchronization, Nexus separates platform-independent network logic from specific implementations such as Velocity and Paper.

#### 🧩 Infrastructure Modules

| Module | Description |
| --- | --- |
| 📘 **API** | Shared contracts and data models for instances, players, registries, messaging, and network operations. |
| ⚙️ **Core** | Redis-backed distributed state, instance registration, health monitoring, admission control, and synchronization. |
| 🔀 **Proxy** | Velocity integration for player routing, connection management, secure transfers, and graceful proxy draining. |
| 🖥️ **Server** | Paper integration for server registration, network coordination, and shared server lifecycle management. |
| ⏳ **Limbo** | Optional holding servers for queueing, maintenance operations, and temporary player transfers. |
| 🎛️ **Orchestrator** | Spring Boot service responsible for queue management, infrastructure coordination, and scaling decisions. |
| ☁️ **Provisioner** | Provider-independent instance provisioning with Vultr and Pterodactyl integrations. |

#### ⚡ Engineering Highlights

- 🌐 **Distributed Network State** — Shared instance and player registries coordinated through Redis.
- 📡 **Real-Time Messaging** — Redis pub/sub communication and cross-instance synchronization.
- 💓 **Instance Health Monitoring** — Heartbeats, automatic stale-instance cleanup, and network availability tracking.
- 🔄 **Graceful Proxy Draining** — Player migration and controlled shutdowns for rolling maintenance.
- 🔐 **Secure Player Transfers** — HMAC-signed, single-use transfer tickets.
- 🚦 **Admission Control** — Global rate limiting, connection capacity management, and queue-based routing.
- ⏳ **Maintenance & Limbo** — Temporary player holding and controlled network re-entry.
- ☁️ **Infrastructure Automation** — Automated provisioning and orchestration through external provider APIs.
- 🧩 **Platform Independence** — Reusable core infrastructure with separate platform-specific integrations.

**🛠️ Technology Stack**

`Java 25` · `Maven` · `Redis` · `Spring Boot` · `Velocity` · `Paper` · `Vultr` · `Pterodactyl`
